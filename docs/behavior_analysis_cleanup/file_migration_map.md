Later that day, the approved non-code relocation moved 78 of these files and 790 files from identified behavior output directories to `/Users/sophiarenauld/behavior_results`. Scripts, autosaves, and project configuration were retained unchanged. Use the [executed relocation plan](relocation_plan_20261110.json) for actual current paths; the source links and proposed paths below are the historical inventory. Code restructuring and consolidation remain proposed.

See the [overview](README.md) for scientific distinctions, dependencies, external roots and migration order. The [JSON inventory](inventory.json) supplies hashes, sizes and source-line evidence.

Source links point to existing files. Proposed destinations are not links because they do not exist yet. `RESULTS_ROOT`, `INPUT_ROOT`, and `LOCAL_STATE_BACKUP` are the proposed external roots in the overview, not approved filesystem locations.
